# Time & Tides Events Android app

This Android app opens the Time & Tides Events booking service with native Android handling for links and file selection.

The Play Store package is generated as an Android App Bundle (AAB) by GitHub Actions. Google Play publication still requires a Google Play Console developer account, app listing information, policy declarations, and review.

The release build is intentionally generated without storing a signing key in this public repository. The Play Console upload/signing setup should use a developer-controlled upload key.
